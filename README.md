# BUAA-SPOC-Course-Auto-Playing-Script

可以速通北航 SPOC 在线视频课的油猴脚本。

## 1. 原理及局限性

### 1.1 换源原理

SPOC 平台的视频播放器会对视频的播放进度进行检测，只有"完整看完"才会记录为已完成。本脚本的做法是：

1. 每 500ms 扫描一次页面，找到视频播放器组件；
2. 把视频的播放地址（`src`）**替换成一个只有约 1 秒的短视频**（托管在我自己的服务器上）；
3. 这个 1 秒的视频会"瞬间播放完毕"，播放器以为你已看完本节课程，于是记录进度；

简单来说：**不是加速播放原视频，而是把原视频换成 1 秒的片段，骗过进度检测系统。** 因此，这个系统 **解决不了高峰时段网络阻塞** 问题。
如果脚本能正常运行，你会看到一个黑色的“测试视频”，然后点击播放后，一秒播放完毕。此时点击“关闭”并查看其他视频即可。
此外，此脚本不能自动播放下一个视频，需要手动关闭视频后点开下一个。但是经我实测，也没多麻烦。

## 2. 使用教程

> 下面假设你完全没有编程经验，请**一步一步照着做**即可。

### 2.1 在浏览器上安装油猴插件（Tampermonkey）

油猴（Tampermonkey）是一个浏览器扩展，可以让用户给网页"挂载"自定义脚本。推荐使用 **Chrome / Edge** 浏览器。

1. 打开浏览器的扩展商店：
   - **Edge**：访问 [Edge 加载项商店](https://microsoftedge.microsoft.com/addons/) ，搜索 `Tampermonkey`；
   - **Chrome**：访问 [Chrome 网上应用店](https://chrome.google.com/webstore/) ，搜索 `Tampermonkey`（若无法访问，可自行搜索"Chrome 离线安装 Tampermonkey"）。
2. 在搜索结果中找到 **Tampermonkey**（图标是一个黑色小猴子），点击「获取 / 添加到浏览器」。
3. 浏览器会弹出确认框，点击「添加扩展」。
4. 安装完成后，浏览器右上角会出现一个**黑色小猴子图标**，说明安装成功。

> 💡 如果图标没出现，点击浏览器右上角的"拼图"图标（扩展管理），把 Tampermonkey 固定到工具栏。

### 2.2 调整相关设置

1. 最重要的一点是：在浏览器设置（右上角三个点 → 设置）中，**找到【扩展】-【篡改猴】-【允许用户脚本】并打开**，否则刷课脚本无法运行。

### 2.3 导入脚本

1. 点击浏览器右上角的**黑色小猴子图标**，在弹出的菜单中点击「**添加新脚本**」（或"Create a new script"）。
2. 页面会打开一个代码编辑框，里面有一些默认内容。**全选（Ctrl+A）并删除**。
3. 把本仓库中的`script.js`中的完整代码**复制粘贴**进去：
4. 按 **Ctrl+S**（Mac 是 **Cmd+S**）保存。编辑器顶部会提示"已保存"。
5. 打开 SPOC 视频播放页，刷新页面。打开浏览器开发者工具（按 **F12** → Console 标签），如果看到 `[SPOC 换源] === 脚本已注入 ===`，说明脚本已生效。
6. 回到油猴图标，菜单里会出现「**立即换源**」命令，点击可手动触发一次换源。

> 修改后记得按 **Ctrl+S** 保存。

## 3. 常见问题

**1. 装了脚本但没反应**
- 检查：按 `F12` 打开 Console，看有没有 `[SPOC 换源]` 开头的日志，如果没有，说明脚本没有正常运行，需要检查油猴插件安装、脚本配置以及设置中**允许用户脚本**已经打开。
- 如果脚本能正常运行但还是没效果，可能有其他问题。

**2. 看完视频后进度回退了**
- 如果在使用这个脚本前你已经看过一部分这个视频了，可能会出现此情况，**解决方案是再刷一遍（再多花一秒钟）**；
- 也有可能纯粹就是这个平台的 bug

**3. 会被学校发现吗？**
- 显然这是有可能的，因此**请自行评估风险。**
